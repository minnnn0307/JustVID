# JustVID

Windows 10/11 x64용 동영상 플레이어. 버전 1.5.0, 이후 Semantic Versioning 적용. 앱 이름과 창 제목에는 버전을 붙이지 않습니다.

## 설치

[JustVID-Setup.exe 다운로드](https://github.com/minnnn0307/JustVID/releases/latest/download/JustVID-Setup.exe)

설치 파일 하나를 받아 실행합니다. 압축 해제가 필요 없으며 .NET 실행 환경과 코덱을 포함해 오프라인 설치가 가능합니다.

## 사용

파일 열기 버튼, Ctrl+O 또는 파일 드롭으로 영상을 엽니다. Space는 재생/일시정지, 좌우 방향키는 5초 이동, M은 음소거, F는 전체 화면, Enter는 일반 창과 직전 최대화/전체화면 모드를 전환합니다. Esc는 영역 선택을 취소합니다.

- 재생바 클릭 또는 드래그: 해당 위치로 이동
- 재생바 마우스 오버: 시간과 영상 미리보기
- Ctrl+왼쪽 드래그: 초록 선택 영역 확대 (1픽셀 선택도 허용)
- Ctrl+오른쪽 클릭: 원본 화면 복구
- 오른쪽 아래 모서리 및 창 테두리: 크기 조절. 영상은 종횡비를 유지합니다.
- 상단 설정 버튼 또는 Ctrl+,: 다크/라이트 및 영상 정보. 볼륨과 테마를 사용자 설정에 저장합니다.

최소 창 크기는 조작을 위한 160×140이며 작은 창에서는 볼륨바, 시간 및 파일명이 순서대로 숨겨집니다. 홍보 문구, 네트워크 요청, 분석 SDK는 없습니다.

## 빌드

Windows 및 .NET 8 SDK:

```powershell
dotnet run --project tests/JustVID.Tests.csproj -c Release
dotnet run --project JustVID/JustVID.csproj
dotnet publish JustVID/JustVID.csproj -c Release -r win-x64 --self-contained true -o artifacts/publish
```

설치 프로그램은 Inno Setup 6에서 `installer/JustVID.iss`를 컴파일합니다. GitHub Actions의 Windows build가 기하 계산 테스트, 앱 빌드, 설치 파일 생성을 수행하며 Artifacts에서 결과물을 다운로드할 수 있습니다. 자동 공개 릴리스는 만들지 않습니다.

게시자는 앱 정보 메뉴에서 Windows UI 언어에 따라 `조민혁` / `Minhyeok Cho`로 표시합니다. 설치 프로그램과 Windows 설치 앱 목록의 게시자는 설치 언어에 따라 지정합니다. 실행 파일의 기본 Company 메타데이터는 Minhyeok Cho입니다. 코드 서명 인증서는 포함하지 않습니다.

## 리소스 및 재생 범위

LibVLCSharp.WPF 3.9.3과 VideoLAN.LibVLC.Windows 3.0.21을 포함합니다. Windows에 별도 코덱을 설치하지 않고 MP4, MKV, WebM, H.264/H.265, VP8/VP9 등 LibVLC가 지원하는 로컬 영상을 재생합니다. 손상 파일, DRM 콘텐츠 및 일부 특수 포맷은 재생하지 못할 수 있습니다. 하드웨어 디코딩을 요청하며 지원하지 않는 경우 엔진의 소프트웨어 디코딩을 사용합니다. 내장 코덱 때문에 이전 Windows 기본 엔진 방식보다 배포 크기가 커집니다. 실행할 때 코덱을 다운로드하지 않습니다.

라이트모드에서는 빈 재생창과 영상 바깥 여백을 밝은 회색으로 표시합니다. 실제 영상의 픽셀 색은 변경하지 않습니다. 음량은 스피커의 음소거/작은 음량/큰 음량 표시와 연동되며 볼륨을 올리면 음소거가 해제됩니다. 크기 조절 표시는 없으며 창 테두리와 모서리 드래그로 크기를 조절합니다.

미리보기는 요청 시에만 보조 디코더를 열고, 180ms 주기로 탐색 요청을 제한하며 마우스가 떠난 뒤 2초 후 해제합니다. 전체 영상의 썸네일을 사전 생성하지 않습니다. 미리보기 표시 속도와 정확도는 코덱/키프레임에 따라 다릅니다. CPU/메모리 사용량은 아직 측정하지 않았습니다.

## Windows 수동 검증

CI의 컴파일 검증 외에 실제 Windows에서 다음을 확인해야 합니다:

1. H.264/AAC 영상의 열기, 재생, 종료 후 재생, 일시정지, 탐색, 음소거 및 파일 교체.
2. 재생/일시정지 중 재생바 미리보기, 빠른 마우스 이동, 미지원 파일 오류, 앱 종료 시 파일 잠금 해제. MP4/H.264, MKV/HEVC, WebM/VP9 및 AAC/AC3/Opus 음성 확인.
3. 레터박스와 세로 영상에서 역방향 및 1픽셀 Ctrl 드래그, 중첩 확대, Ctrl+우클릭 복구, 선택 중 Esc.
4. 작은 창/큰 창, 최대화/전체 화면, 다중 모니터 및 100/150/200% DPI에서 비율과 선택 좌표.
5. 한국어/영어 설치 시 게시자, 앱 아이콘, 테마/볼륨 저장, 설치 및 제거.
6. 작업 관리자에서 1080p/4K 재생 및 미리보기 전후 CPU/GPU/메모리 측정. 하드웨어와 코덱별 결과 기록.

- 크기 조절 표시를 제거합니다. 창 테두리와 모서리의 크기 조절 동작은 유지합니다.

Windows CI에 합성 영상의 실제 디코딩 및 네이티브 Ctrl/마우스 입력, 선택 표시, 1픽셀 확대, 복구, 작업표시줄 영역/창 복원 확인을 추가했습니다. 테스트 영상은 FFmpeg smptebars로 만든 320×180 H.264 무음 영상입니다. 선택 오버레이 검증 이미지는 별도 CI 아티팩트로 저장합니다. 다중 모니터/DPI 및 Windows 10/11 외관의 수동 검증은 별도로 필요합니다.

## 1.1.0 변경

- 전체화면에서는 하단 컨트롤을 기본적으로 숨깁니다. 마우스를 하단 84 DIP 영역으로 이동하면 나타나고, 2.5초 동안 움직임이 없으면 다시 숨깁니다. 슬라이더를 드래그하는 동안에는 숨기지 않습니다.
- 전체화면 컨트롤은 영상 위 별도 팝업으로 표시해 나타나거나 사라질 때 영상 크기와 확대 영역이 변하지 않습니다.
- 아무 영상도 열지 않았을 때 중앙에 초록 재생 아이콘과 JustVID 로고를 표시합니다. 중앙 파일 열기 버튼은 제거하며 하단 ＋, Ctrl+O 및 파일 드롭은 유지합니다.
- Esc로 전체화면과 일반 최대화를 모두 해제합니다. 최대화 상태에서 전체화면에 들어갔어도 Esc를 누르면 일반 창으로 돌아옵니다.
- 설치 프로그램에 선택 가능한 바탕화면 바로가기 만들기를 추가합니다(기본 미선택).

새로운 전체화면 컨트롤 동작과 설치 선택 기능을 추가했으므로 마이너 버전을 올립니다.

## 1.2.0 변경

- 전체화면 컨트롤 영역에서 마우스를 빼면 즉시 숨깁니다. 슬라이더 드래그 중에는 유지하고 드래그를 마친 뒤 영역 밖에 있으면 숨깁니다. 영역 안에서의 기존 비활동 2.5초 숨김도 유지합니다.
- 창 모드 전환 키를 Esc에서 Enter로 변경합니다. 전체화면/최대화에서 Enter를 누르면 일반 창으로 돌아오고, 다시 누르면 직전 모드로 복원합니다. 최대화 후 전체화면에 들어갔다가 Enter를 누른 경우에도 복원 대상은 전체화면입니다.
- F는 기존 전체화면 전환을 유지하고 Esc는 영역 선택 취소만 수행합니다. 이전 모드가 없는 첫 Enter는 전체화면으로 전환합니다. 키를 길게 눌러 발생하는 자동 반복 입력은 모드를 반복 전환하지 않습니다.
- 새 이전 모드 복원 동작을 추가하므로 마이너 버전을 올립니다.

## 1.4.0 변경

- 설정 아이콘을 Windows 기본 설정 톱니바퀴 모양으로 교체합니다.
- 라이트모드의 컨트롤과 손잡이를 연한 연두색으로 맞추고 시간은 큰 고정폭 숫자와 배경 배지로 표시합니다.
- 재생바의 투명 입력 영역과 손잡이 범위를 넓히고 마우스를 캡처해 선에서 벗어나도 드래그를 이어갑니다. 드래그 중 위치만 표시하고 놓을 때 한 번 탐색합니다.
- 미리보기에는 오디오 출력/음량/음소거 API를 호출하지 않으며 드래그 중에는 미리보기를 시작하지 않습니다.

- 설정의 자막 탭에서 크기 50~200%, 아래쪽 여백 0~300px 및 외부 자막 파일을 지정하고 적용합니다. 적용 시 현재 위치/일시정지 상태/음량을 보존하여 영상을 이어갑니다. 크기와 위치는 다음 실행에도 저장합니다. 영상에 박힌 자막이나 이미지 기반 자막의 글꼴 크기는 바뀌지 않습니다.
- Windows 테스트에서 무음이 아닌 합성 AAC 오디오의 PCM 샘플을 수집하여 드래그 중 연속 디코딩과 탐색 뒤 재개를 확인합니다. 실제 출력 장치별 체감 지연은 별도 확인이 필요합니다.

## 1.5.0 변경

- 상단바를 화면 상단으로 드래그하면 작업표시줄을 제외한 영역에 최대화합니다.
- 최대화된 상단바를 아래로 드래그하면 기존 크기의 창으로 복원하고 마우스 위치에 맞춰 이동을 이어갑니다. Enter의 이전 모드 복원과 함께 동작합니다.
- 라이트모드의 연두색 아이콘과 슬라이더 손잡이에 얇은 초록 테두리를 적용합니다.
- Windows 네이티브 입력 검증에 상단 드래그 최대화, 아래로 드래그 복원, 원래 창 크기와 포인터 위치 및 Enter 전환 검사를 추가합니다.
